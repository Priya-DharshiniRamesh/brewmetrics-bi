# Reflection

Working on the BrewMetrics BI project with GitHub Copilot helped me understand how AI assistance can support the development of a Power BI solution. Copilot was directly useful when creating DAX measures because it provided suggestions for calculations such as sales growth, running total, ranking, and average transaction value. These suggestions gave me a starting point and helped me understand different DAX functions and their usage.

However, Copilot's suggestions were not always completely correct. For the Average Sales per Transaction measure, the initial approach used `COUNTROWS`, which did not accurately represent the number of transactions. I reviewed the logic and corrected it by using `DISTINCTCOUNT(Fact_Sales[sale_id])`. This was an important learning experience because it showed that Copilot-generated code still needs to be checked against the actual data model and project requirements.

Working with the complete Git commit history also changed the way I approached the project. Instead of creating the entire Power BI report at once, I developed it step by step. I first created the star schema, then added each DAX measure separately, followed by the dashboard and documentation. Each commit clearly recorded a stage of development, making it easier to track changes and identify when corrections were made.

Overall, this project showed me that combining Git, Power BI, and Copilot can make BI development more organized, traceable, and easier to review. It also taught me the importance of validating AI-generated suggestions rather than accepting them without checking.
